## 🔧 Technical Details

### @verbatim vs @@ Escape

**Problem:** Blade treats @context/@type as directives.

**Pattern 1 — @verbatim (Static):**
```blade
@push('head')
@verbatim
<script type="application/ld+json">
{ "@context": "https://schema.org", "@type": "WebSite" }
</script>
@endverbatim
@endpush
```

**Pattern 2 — @@ (Dynamic with {{ }}):**
```blade
@push('head')
<script type="application/ld+json">
{ "@@context": "https://schema.org", "@@type": "LocalBusiness",
  "name": "{{ addslashes($provider->name) }}" }
</script>
@endpush
```

**Rule:** Static -> @verbatim | Dynamic -> @@ | Never mix.

### Blade Compile Check
```cmd
php artisan view:clear
php artisan view:cache
```

### Stale Cache Fix (Windows)
```cmd
:: Laragon Stop
del /F /Q storage\framework\views\*.php
del /F /Q bootstrap\cache\*.php
:: Laragon Start
:: Ctrl+Shift+R
```
